# Workflow: Plan

Goal: lock a decision-complete plan for plot, constraints, and quality gates.

## Steps

1. Clarify scope:
   - genre, POV, tense, chapter count, ending type
   - banned phrases and required motifs

2. Build plot skeleton:
   - create scene list with `worldTime`, `narrativeTime`, `location`
   - map actor knowledge and clue lifecycle (`SEED`/`RESOLVE`)

3. Define risk controls:
   - epistemic checks for secrets and reveal timing
   - spatial checks for physical interactions
   - causality checks for flashback/branch scenes

4. Register acceptance:
   - compile `error=0`
   - manuscript lint passes required constraints
   - Korean proofreading pass for final episode text
