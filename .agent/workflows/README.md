# Workflows

Runbooks for deterministic novel production with Antigravity.

Main flows:

- `00-setup.md`: clone-to-ready bootstrap
- `10-plot-compile.md`: rough plot -> NVL -> compile-repair loop
- `20-write-novel.md`: compile-pass log -> prose
- `30-write-episode.md`: EpisodePack -> draft -> lint -> proofread
- `40-remove-citations.md`: publication cleanup

Command-style aliases (oh-my-ag inspired):

- `setup.md`: environment and structure doctor checks
- `plan.md`: story intent -> constraints -> NVL planning
- `orchestrate.md`: full two-agent/compile pipeline routing
- `coordinate.md`: human-in-the-loop role handoff sequence
- `review.md`: consistency + Korean quality gate review
- `debug.md`: compile failure triage and targeted fixes
- `tools.md`: MCP tool routing map
