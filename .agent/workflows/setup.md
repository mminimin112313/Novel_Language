# Setup Workflow
Trigger: `/setup`

## Goal
Initialize project tooling and standards.

## Steps
1. **Git**: Ensure `.gitignore` exists and covers sensitive files.
2. **Linting**: Setup ESLint/Prettier.
3. **Testing**: Install test runner (Vitest/Jest).
4. **Hooks**: Setup pre-commit hooks (Husky).
5. **CI**: Create basic CI workflow (GitHub Actions).
