# Agent Role Files

This directory stores Antigravity runtime assets for this project.

- `*.agent.yaml`: role objectives, I/O contracts, and hard constraints.
- `.agent/skills/`: reusable skill packs (`SKILL.md`).
- `.agent/workflows/`: runbooks (`/commands` style task flows).
- `.agent/rules/`: project/editorial/compiler policies.
- `.agent/config/user-preferences.yaml`: user and CLI preference defaults.
- `.agent/mcp.json`: local MCP server registration template.

Shared cross-skill resources live under `.agent/skills/_shared/`.
