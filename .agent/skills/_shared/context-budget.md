# Context Budget (Novel Production)

Use deterministic artifacts first; load prose context only when needed.

## Priority Order

1. compiler diagnostics (`error` first)
2. episode pack constraints
3. AQL query results
4. latest draft text
5. older drafts and brainstorming notes

## Practical Rules

- never load all chapters at once
- keep only active scene windows in context
- prefer `[[EVT:###]]` evidence over free-form recollection
- summarize old context into bullet facts before continuing
