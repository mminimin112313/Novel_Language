# Implement Slice Workflow
Trigger: `/implement-slice [slice-name]`

## Goal
Implement a small, vertical slice of functionality (DB -> API -> UI) completely.

## Steps
1. **Context**: Understand the slice requirements from `plan.md` or `task.md`.
2. **Backend**: Implement DB schema and API logic.
3. **Test**: Write tests for the backend logic.
4. **Frontend**: Implement the UI component interacting with the API.
5. **Verify**: Run manual or automated verification for the full slice.
6. **Commit**: `git commit -m "feat: implement [slice-name]"`
