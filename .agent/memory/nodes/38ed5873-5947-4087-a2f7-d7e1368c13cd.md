# Plan Feature Workflow
Trigger: `/plan-feature [description]`

## Goal
Create a comprehensive implementation plan before writing code.

## Steps
1. **Analyze Requirements**: Understand what needs to be built.
2. **Identify Risks**: Surface potential blockers (Security, Performance).
3. **Break Down**: Split work into small, verifiable vertical slices.
   - Slice 1: Core Schema & API
   - Slice 2: Basic UI & Integration
   - Slice 3: Polish & Edge Cases
4. **Define Verification Plan**: How will we test each slice?
5. **Output**: Update `task.md` and/or `implementation_plan.md`.

## Example Output
```markdown
# Implementation Plan: [Feature Name]

## Proposed Changes
- [ ] Database schema changes
- [ ] API endpoints

## Verification
- Automated tests
- Manual validation steps
```

**WAIT for user approval before starting implementation.**
