## 기승전결 구조 (4막 구조)

### 起 (기) - 도입 (전체의 ~25%)

**목표**: 상황 설정, 캐릭터 소개, 일상/균형 상태

| 비트 | 설명 | 예상 씬 |
|:-----|:-----|:--------|
| **훅(Hook)** | 독자를 끌어들이는 첫 순간 | |
| **설정(Setup)** | 세계/인물/상황 소개 | |
| **촉발사건(Inciting)** | 균형을 깨는 사건 | |

**이 파트의 핵심 질문**: _{독자가 알아야 할 것}_

---

### 承 (승) - 전개 (전체의 ~25%)

**목표**: 갈등 심화, 캐릭터 반응, 시도와 실패

| 비트 | 설명 | 예상 씬 |
|:-----|:-----|:--------|
| **반응(Reaction)** | 주인공의 첫 대응 | |
| **시도(Attempt)** | 문제 해결 시도 | |
| **장애(Obstacle)** | 예상치 못한 방해 | |

**이 파트에서 상승하는 긴장**: _

---

### 轉 (전) - 전환점 (전체의 ~25%)

**목표**: 결정적 변화, 진실 발견, 방향 전환

| 비트 | 설명 | 예상 씬 |
|:-----|:-----|:--------|
| **위기(Crisis)** | 최악의 상황 | |
| **전환(Turn)** | 새로운 정보/결심 | |
| **결심(Decision)** | 돌이킬 수 없는 선택 | |

**미드포인트 전환**: _{+에서 -로, 또는 -에서 +로}_

---

### 結 (결) - 결말 (전체의 ~25%)

**목표**: 갈등 해소, 새로운 균형, 다음 에피소드 암시

| 비트 | 설명 | 예상 씬 |
|:-----|:-----|:--------|
| **클라이맥스(Climax)** | 최종 대결/결정 | |
| **해소(Resolution)** | 결과와 여파 | |
| **훅(Hook-forward)** | 다음 에피소드 암시 | |

**독자가 느껴야 할 감정**: _
