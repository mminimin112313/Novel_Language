# References: Nexus-CLI

## GitHub Repositories

### Core Models & Implementation
- **[FlagOpen/FlagEmbedding](https://github.com/FlagOpen/FlagEmbedding)**: Official implementation of BGE-M3 and Reranker models. Essential for `BGEM3FlagModel` and `FlagReranker`.
- **[yuniko-software/bge-m3-qdrant-sample](https://github.com/yuniko-software/bge-m3-qdrant-sample)**: Example of hybrid search with BGE-M3 and Qdrant in Python.
- **[qdrant/qdrant-client](https://github.com/qdrant/qdrant-client)**: Official Python client. Reference for Local Mode (`path="db_path"`) configuration.

### CLI & RAG Architectures
- **[PPierzc/hive](https://github.com/PPierzc/hive)**: Reference for CLI structure using `typer` and file scanning logic.
- **[run-llama/semtools](https://github.com/run-llama/semtools)**: Semantic search CLI toolkit; source for result formatting ideas.
- **[zylon-ai/private-gpt](https://github.com/zylon-ai/private-gpt)**: Standard for local RAG; reference for chunking strategies and metadata management.
- **[khoj-ai/khoj](https://github.com/khoj-ai/khoj)**: Personalized AI search tool; reference for local search engine architecture.
- **[chatchat-space/Langchain-Chatchat](https://github.com/chatchat-space/Langchain-Chatchat)**: Extensive use of BGE models in RAG; source for optimization tips and prompt templates.
