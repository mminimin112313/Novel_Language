# Tech Stack

## 1. Core Runtimes
- **Node.js**: v18+ (Required for core/browsing skills)
- **Python**: 3.9+ (Required for memory/backend capabilities)

## 2. Agent Skills
- **Browsing**: Playwright (Headless/Headed automation)
- **Memory**: Sentence Transformers (Embeddings) + SQLite (Vector Storage)

## 3. Infrastructure
- **Agent System**: Custom Layered Domain Architecture (`.agent/`)
- **Package Managers**: npm (browsing), pip (memory)
