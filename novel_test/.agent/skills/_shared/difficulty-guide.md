# Difficulty Guide (NVL Tasks)

## Level 1: Routine

- typo fixes, spacing/grammar cleanup
- small line-level NVL repairs with clear diagnostics

## Level 2: Moderate

- multi-scene causality alignment
- clue lifecycle fixes (`SEED`/`RESOLVE`)
- episode draft that must satisfy strict constraints

## Level 3: Complex

- branch or flashback-heavy timelines
- large cast with epistemic constraints
- long-form novel generation with per-chapter compile loops

Escalation rule: for Level 3, split work into plan -> compile -> write -> review gates.
