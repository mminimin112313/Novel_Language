# Reasoning Templates

Use one template per stage to keep outputs auditable.

## Plot Compile Template

1. target behavior
2. failing diagnostics
3. minimal NVL patch
4. expected side effects
5. re-check command

## Episode Draft Template

1. episode objective
2. selected events (`[[EVT:###]]`)
3. outline beats
4. draft pass
5. lint/proofread actions

## Review Template

1. checks run
2. failures and severity
3. accepted risks
4. release decision
