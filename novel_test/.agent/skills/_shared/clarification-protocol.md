# Clarification Protocol (Novel Domain)

When requirements are ambiguous, use this protocol before drafting text.

## Ambiguity Levels

- `LOW`: core story intent is clear. Proceed with explicit assumptions.
- `MEDIUM`: multiple valid directions. Offer 2-3 options with trade-offs.
- `HIGH`: cannot write safely. Ask targeted clarification questions first.

## Must-Ask Cases

- POV/tense/style is unspecified but materially changes output.
- hard constraints conflict (e.g., "no violence" with a murder mystery climax).
- canon facts are missing for sequel or shared universe writing.

## Default Assumptions (if user does not answer)

- language: Korean
- POV: third-person limited
- tense: past
- chapter style: cinematic
- priority: compile consistency over decorative prose
