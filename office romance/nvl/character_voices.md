# 캐릭터 음성 프로필 (Character Voices)

---

## 김지우 (Kim_Jiwoo) - 주인공

**음성 유형**: 내성적 신입, 관찰자

| 측면 | 패턴 |
|:-----|:-----|
| **문장 길이** | 생각은 길고, 말은 짧음 |
| **톤** | 조심스러움, 자기 의심 |
| **어휘** | 공손어, 직장 신입 말투 |
| **특징** | 속으로 혼잣말 많음, "...뭐지?" |

**대화 예시**:
```
"아, 네... 감사합니다."
(속으로) 왜 갑자기 친절한 거지? 뭔가 이상해.
```

## 박서준 (Park_Seojun) - 남주

**음성 유형**: 무뚝뚝한 팀장, 숨겨진 배려심

| 측면 | 패턴 |
|:-----|:-----|
| **문장 길이** | 극도로 짧음 (3-7단어) |
| **톤** | 차갑지만 행동으로 표현 |
| **어휘** | 업무 용어, 명령형 |
| **특징** | 말보다 행동, "...그래." |

**대화 예시**:
```
"야근?"
"이거."
(커피를 건네고 돌아선다)
```
